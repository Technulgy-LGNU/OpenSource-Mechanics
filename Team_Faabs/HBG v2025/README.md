# Team Faabs 2025 Robot

This repository contains mechanics of our 2025 robot.
Mechanics are designed with Autodesk Inventor 2025 Professional.

This Robot was used for the 2025 RoboCup Junior.

Autodesk Inventor is available for free for students.
